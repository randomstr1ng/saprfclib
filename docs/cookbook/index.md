# Cookbook

Practical recipes for common saprfclib tasks. Each recipe is a self-contained example
that you can copy and adapt for your own use.

## Recipes

- [TABLE Parameters](table-parameters.md) — Read and write ABAP TABLE parameters
- [RFC Server](rfc-server.md) — Register a Python function as an SAP RFC function module
- [tRFC / qRFC Submit](trfc-submit.md) — Transactional and queued RFC with TID lifecycle
- [Connection Pool](connection-pool.md) — Thread-safe connection pool for concurrent workloads
- [SNC Connection](snc-connection.md) — Encrypted and authenticated connections via SNC (X.509)
- [WebSocket RFC](websocket-rfc.md) — Connect to SAP BTP ABAP Environment via WebSocket RFC
